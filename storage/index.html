Privacy and storage

Nothing is sent anywhere. Your songs, recordings, transcripts and documents stay on this device. Mixtape has no account, no server of its own and no tracking, and this page is not able to contact any other site.

This page shows everything Mixtape keeps here, lets you copy it all into one file, and lets you remove it.

Back up everything to one file

One file holds your songs with their sound, playlists and favourites, lyrics, transcripts and the sensitive marks on them, Studio mixes and settings. Keep it on a USB stick or another disk. It is made on this device and goes only where you put it.

Not in the file: the Cutter’s last session and the Reader’s recent list (they point at files on this device, which a backup cannot carry), and the downloads, which Mixtape fetches again when needed.

Restore from a backup

Choose a backup file and Mixtape adds what is in it to what is already here. Nothing on this device is replaced or removed: a song, transcript or mix you already have is left exactly as it is. The whole file is checked first, and a file that is cut short or damaged is refused before anything is added.

Forget everything on this device

Removes all of the above from this browser: every song, recording, lyric, playlist, favourite, transcript, sensitive mark, Studio mix, the Cutter’s session, the Reader’s recent list, your settings and the downloaded recognisers. Mixtape’s own pages stay, so it still opens offline. The files on your disk that you added things from are not touched.

This cannot be undone. Back up first if you might want any of it again, and close other Mixtape windows so they do not save things back.
